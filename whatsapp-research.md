Official Meta source reviewed: https://developers.facebook.com/documentation/business-messaging/whatsapp/webhooks/overview

Verified facts: WhatsApp Business Platform webhooks notify an application about incoming messages, outgoing message statuses, calls, and account/template changes. A production integration requires a configured webhook endpoint. Required permissions include whatsapp_business_messaging for messages/calls webhooks and whatsapp_business_management for other webhook fields. The App Dashboard WhatsApp Configuration panel is used to subscribe to fields; the messages field covers incoming messages and statuses of outgoing messages. Meta retries webhook delivery when the endpoint does not return HTTP 200, for up to 7 days with decreasing frequency. Implementation must include GET verification (hub.mode, hub.verify_token, hub.challenge), POST JSON receipt, fast HTTP 200 response, and idempotent event handling.
